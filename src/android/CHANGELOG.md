# VioletWire Android

## [1.1]

### Additions

- Follow and Subscribe buttons on channel profiles
- Subscribe button in the stream player
- Twitch and Kick channel points and rewards
- Auto-claim setting for Twitch bonus points
- Separate chat notices for passive and bonus points
- Reward redemption details in chat
- Follower counts and bios on Kick profiles
- Kick stream uptime, tags and game stats
- Tap badges and emotes to see their names
- Saved browse lists and scroll positions
- Refresh button for the viewer list
- Dismissible chat restriction notices
- Chat resize hints
- Data Saver tips and a quality-settings shortcut
- Startup screen with a retry option
- Changelog shown once after each update, with an OK button

### Replaced

- Player volume button with an audio compressor
- Full Following-page reloads with background updates
- Technical profile errors with readable explanations

### Fixes

- High Kick stream delay and repeated buffering
- Twitch repeatedly restarting the ad proxy
- Streams going dark when opening profiles or emotes
- Some Kick profiles failing to load
- Channel rewards failing to open
- Stream thumbnails taking too long to appear
- OLED mode still showing purple backgrounds
- Chat controls overlapping on small screens
- Incorrect follow and subscription status
- Audio leveling and cleanup when closing streams
- Badge and emote names disappearing too early

### Removed

- Extra refresh button in the rewards window
- Duplicate channels when loading more streams
- Duplicate emote popups inside chat profiles
